# 다른 기업들은 마케팅을 어떻게 하나

국내 기업 54곳의 마케팅 활동(브랜드·캠페인·멤버십·세일·팝업·콜라보·교육·AI)과 국내 광고시장 통계, 해외 대표 사례 14곳. 2026-11-24 기준 조사.

- **요약본**: `marketing-cases-summary.pdf`(`summary.html` 인쇄) — 결론, 기능별 대표 활동, 공통 패턴, 광고시장 숫자.
- **본문**: `index.html`(필터·검색), 인쇄본 `marketing-cases.pdf`.
- **데이터**: `cases.json`(합친 데이터), `data/*.json`(묶음별 원자료), `data/insights.json`(해석).

```bash
python3 build.py && "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --no-pdf-header-footer \
  --print-to-pdf=marketing-cases.pdf "file://$PWD/index.html"
# 요약본은 summary.html → marketing-cases-summary.pdf
```

## 한눈에 보기

- 광고는 마케팅의 일부일 뿐입니다. 국내 기업들이 가장 많이 쓴 활동은 광고, 데이터·AI, 오프라인·이벤트(각 27곳), 멤버십·CRM(25곳), 콘텐츠·브랜드 캠페인(각 22곳) 순이었습니다. 한 회사가 보통 5~7가지를 동시에 합니다.
- 돈을 가장 많이 버는 장치는 멤버십입니다. 컬리는 구독자 20%가 월 거래액의 70% 이상을 만들고, 배민은 주문의 약 50%가 배민클럽 구독자에게서 나옵니다. 반대로 해피포인트는 제휴·혜택이 줄면서 MAU가 494만에서 272만으로 줄었습니다.
- 세일을 '정해진 때 여는 행사 브랜드'로 만듭니다. 올영세일(연 4회), 무진장 블프(2,830억원), 29CM 이구위크(1,749억원), 이마트 고래잇 페스타(2,300만 명 참여)처럼 이름 붙은 정기 행사가 매출의 큰 축입니다.
- 오프라인 팝업·플래그십은 '체험하고 가입시키는 곳'입니다. 무신사 메가스토어 성수는 신규·첫 구매 회원 6만4,861명, 올리브영N 성수는 1년 250만 명을 모았습니다. 다만 GS25 도어투성수는 100만 명을 모으고도 임대료 때문에 문을 닫았습니다.
- 광고비 쓰는 방식은 회사마다 극단적으로 다릅니다. 다이소는 매출의 약 0.1%, 배민은 약 1%, 야놀자는 약 10%, 여기어때는 약 20%(2022)를 광고선전비로 썼습니다. 국내 총광고비는 17조1,263억원(2024)이고 그중 59%가 온라인입니다.

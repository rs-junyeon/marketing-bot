# 마케팅 자동화는 무엇을, 어떤 툴로 하나 — 국내 기업 기준

마케팅 봇·자동화 활용 사례와 사용 툴을 조사했습니다. 활용 사례와 통계는 국내 기업·국내 조사만 넣었습니다. 툴은 국내 툴과, 해외 툴 중 국내 사용 근거(국내 고객사·한국 지사·파트너·국내 사용 통계)가 확인된 것만 넣었습니다. 7개 영역을 업무별로 나눠 해결하는 문제, 자동화 범위, 사람이 맡는 범위를 정리했고, 사람이 직접 하는 영업·입소문은 뺐습니다. 사용자가 거의 없는 상태에서 시작한 초기·소규모 사례는 따로 모았고, 국내 사례가 부족한 부분은 해외 사례로 보충했습니다. 마케팅 봇은 알에스팀이 자사 서비스 마케팅에 쓰는 내부 도구라는 전제로 방향을 정리했습니다. 2026-11-26 조사 · 작성 전준연

- **회의용 요약본**: `automation-summary.pdf`(`summary.html` 인쇄) — 결론, 영역별 업무 지도, 대표 활용 사례, 방향 후보·회의 질문.
- **본문**: `index.html`(툴 필터·검색), 인쇄본 `automation-tools.pdf`.
- **범위**: 기본은 국내 버전(툴은 국내 툴 + 국내 사용 근거가 있는 해외 툴, 활용 사례는 국내 기업, 통계는 국내 조사). 해외 포함 전체판은 `python3 build.py --all` → `index-all.html`·`summary-all.html`(해석은 `data/insights-all.json`).
- **데이터**: `tools.json`(국내 버전 합친 데이터), `data/*.json`(영역별 원자료, 8~10은 국내 보강, 11은 해외 툴 국내 사용 근거, 12~14는 초기·소규모 사례), `data/insights.json`(국내 해석).
- **전달본**: `./final.sh` → build.py, PDF 2개 인쇄, `../final/`에 한글 이름으로 복사.

## 한눈에 보기

- 사람이 아예 빠지는 업무는 없었습니다. 42개 업무 모두 기계가 초안 작성·발송·집계를 맡고, 사람은 목표·예산 설정, 기준 정의, 승인, 결과 해석을 맡습니다. 국내 사례도 같습니다. 토스는 큰 설계와 최종 판단을 사람이 하고, 카카오스타일은 MD가 입력한 뒤 AI 결과를 사람이 검수합니다.
- 국내 대기업·플랫폼은 직접 만들어 씁니다(9곳). 토스 광고 푸시 클릭률 2배 이상, 현대카드 반응률 최대 6배·마케팅 설계 최대 3일 → 20~40분, KT 안내 문자 작성 30~60분 → 약 5분, 롯데홈쇼핑 배너 1건 약 10초, 카카오스타일 기획전 제작 몇 주 → 몇 시간. 공통점은 사내 고객 데이터에 생성형 AI를 붙여 마케터가 직접 쓰는 도구로 만든 것입니다.
- 스타트업·커머스는 국내 SaaS를 조합합니다. CRM 메시지는 핵클·데이터라이즈·노티플라이, 상담은 채널톡 ALF, 측정은 에어브릿지, B2B 리드는 리캐치·세일즈맵을 씁니다. 바이트랩 장바구니 이탈 메시지 전환율 약 23%, 라라스윗 상담 해결률 85.8%, 원티드랩 광고비를 2배 이상 늘리면서 CPA 38% 이상 절감(모두 회사 발표).
- 사용자가 거의 없을 때 효과가 난 자동화는 '처음 사람을 모으는' 쪽에 몰려 있습니다. 국내 초기·소규모 사례는 숏폼·상세페이지 대량 제작(클린리펄슨 한 달 매출 5~6배, 엠시베딩 한 달 인스타 팔로워 1,000명)과 B2B 문의→미팅 자동 예약·웨비나(머스트무브 6주 만에 유료 고객사 100곳, 마인드로직 1시간 웨비나로 리드 약 400명)였고, 해외에서는 콜드메일 시퀀스(Paraform 아웃바운드만으로 고객 100곳 이상)와 SEO 페이지 자동 생성도 있었습니다. 행동 기반 메시지는 보낼 대상이 있어야 해서, 출시 전 구독자·카카오 친구를 먼저 모은 경우에만 효과가 났습니다(Wimp Decaf 오픈일 주문 76건, 짬뽕가온 6개월 만에 카카오 친구 약 4,000명).
- 효과가 가장 고르게 나온 곳은 리포트·분석 자동화입니다. 크몽 일일 리포트 시간 83% 단축, 제로원애드 리포트 작성 70%↓, 국내 광고대행사 주간 리포트 주 8시간 이상 → 20분, 무신사 분석 2~3일 → 15분, W컨셉 월 40시간 절감. 최근에는 Claude·ChatGPT를 에어브릿지·브레이즈 같은 툴에 MCP로 연결하는 방식이 늘고 있습니다.
- 광고는 매체가 직접 자동화했습니다. CJ올리브영(Google PMax) ROAS 42% 증가, 컴투스홀딩스(Meta Advantage+) ROAS 12배, 네이버 ADVoost 광고주 구매 ROAS 810% → 1,830%. 네이버는 AI가 광고 매출 증가분의 60% 이상을 만들었다고 밝혔습니다.
- 범용 AI는 이미 일상이지만, 마케팅 자동화 도구는 아직 초기입니다. 국내 마케터 82.7%가 거의 매일 AI를 쓰고 ChatGPT 국내 MAU는 2,470만입니다. 반면 국내 CRM 담당자 중 AI 기반 도구를 쓰는 기업은 12%, 서울 소상공인 AI 활용은 9.7%입니다. 디지털 마케터 95.5%가 AI를 써 봤지만 데이터 분석·광고 집행 자동화는 아직 가능성을 확인하는 단계로 봅니다.

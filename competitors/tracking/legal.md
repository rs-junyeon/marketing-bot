# 경쟁사 광고·언급 자동 수집, 법적으로 어디까지 괜찮을까? (쉬운 요약)

> **주의: 법률 자문이 아닙니다.** 사내 마케팅 봇 기획용 사전 조사입니다(조사일 2026-11-27). 로그인 없이 볼 수 있는 법령·판결·약관 원문만 읽었습니다. 실제로 만들기 전에는 변호사 검토를 받아야 합니다. 원문 인용 58개와 출처 링크는 `legal.json`에 있습니다.

## 한눈에 보는 표

| 방식 | 위험도 | 한 줄 설명 | 이렇게 하면 비교적 안전 |
|---|---|---|---|
| **A. 사람이 직접 보고 정리** | 🟢 낮음 | 공개된 글·광고를 사람이 보는 건 정상 이용이에요. 글 1~2개 옮겨 적는 건 DB 침해로 안 봐요. | 로그인해야 보이는 글은 제외. 요약과 링크만 적기. 경쟁사 목록·가격표를 통째로 베끼지 않기. 닉네임은 적지 않기. |
| **B. Meta 광고 라이브러리·Google 광고 투명성 센터** | 🟢 낮음 (웹 화면을 긁으면 🔴) | 공식 도구라 조회는 괜찮아요. 그런데 Meta는 허락 없는 자동 수집을 금지하고, Google은 "정보·연구 목적"으로만 쓰고 팔면 안 된대요. | 화면은 사람이 보기. 자동화는 Meta 공식 API로만 하기(단, 한국 일반 광고는 API로 안 나올 수 있음). 결과를 외부에 팔지 않기. |
| **C. 네이버 검색 API(블로그·카페글)** | 🟡 중간 | 네이버가 허락한 길이라 "침입"은 아니에요. 그런데 약관이 엄격해요. **저장 금지(예외: 최대 21일), 가공 금지, AI에 넣기 금지**. 하루 25,000번까지 호출할 수 있어요. | "네이버 검색결과"라고 표시하고 원문 링크와 함께 그대로 보여주기만. DB에 쌓아 두거나 AI로 요약하면 약관 위반. 신규 키는 NAVER API HUB에서 받아야 함. |
| **D. 크롤러로 카페·블로그·당근 긁기** | 🔴 높음 | 네이버 카페 robots.txt는 모든 봇을 막아요. 네이버·당근 약관은 허락 없는 자동 수집을 금지해요. 여기어때는 야놀자를 크롤링했다가 형사재판에선 무죄가 났지만, **민사재판에서 10억원을 물어줬어요**. | 하지 않기. 꼭 필요하면 플랫폼에 먼저 서면 허락(제휴)을 받기. |
| **E. 닉네임 같은 개인정보가 섞일 때** | 🟡 중간 | 닉네임도 블로그 주소 같은 다른 정보와 합치면 누군지 알 수 있어서 개인정보가 될 수 있어요. 공개된 글이라도 마음대로 모아도 되는 건 아니에요. | 닉네임·ID는 저장하지 않거나 가리기. 필요한 것만 모으고 기간이 지나면 지우기. 사람 단위로 분석하지 않기. 요청이 오면 어디서 모았는지 알려주기. |
| **F. (참고) 가짜 후기 올리기 / 경쟁사 베끼기** | 🔴 높음 | 직원이 쓴 홍보글을 손님 후기처럼 올리면 표시광고법 위반이 될 수 있어요(최대 징역 2년 또는 벌금 1억5천만원). AI로 만든 가짜 인물 후기도 마찬가지예요. 경쟁사 문구·디자인·데이터를 베끼면 저작권·부정경쟁 문제가 생겨요. | 홍보글은 제목이나 첫 줄에 "광고"나 "○○사 직원 작성"이라고 표시하기. AI 가짜 후기는 만들지 않기. 경쟁사는 관찰하고 요약만 하고, 복제하지 않기. |

## 꼭 기억할 판례 2개

1. **여기어때 vs 야놀자 (2016년 크롤링)**
   - 형사사건(대법원 2022. 5. 12. 선고 2021도1533): 무죄. 그래도 대법원은 접근해도 되는지 판단할 때 "보호조치나 이용약관 등"을 본다고 했어요.
   - 민사사건(서울중앙지법 2018가합508729): 부정경쟁행위로 인정돼 **10억원 배상**, 모은 정보 보관도 금지됐어요. 처음엔 직원이 손으로 모으다가 크롤러로 바꾸면서 문제가 커졌어요.
2. **잡코리아 vs 사람인**: 서울고등법원(2017년 보도)은 허락 없이 채용정보를 크롤링해 영업에 쓴 것을 데이터베이스제작자 권리 침해로 봤어요.

→ 교훈: **"형사처벌만 피하면 된다"가 아니에요. 민사 배상과 약관 위반(계정·키 차단)이 진짜 위험이에요.**

## 결론 (회의 질문에 대한 답)

- **"역추적은 서비스로는 못 들어갈 것 같다"** → **크롤러(D) 방식이라면 맞는 말이에요.** 사내용이어도 약관 위반과 부정경쟁 위험은 그대로예요.
- 그래도 **역추적 자체가 불법은 아니에요.** 아래처럼 범위를 좁히면 사내 기능으로 만들 수 있어요.
  1. **지금 할 수 있는 것**
     - A: 담당자가 직접 보고 정리
     - B: 광고 투명성 도구를 사람이 조회(Meta는 공식 API만 자동화)
     - C: 네이버 검색 API를 "실시간 검색 창"처럼 원문 링크와 함께 그대로 보여주기
  2. **허락이 필요한 것**: API 결과를 저장하거나 AI로 요약하기, 카페·블로그·당근 본문 자동 수집. 플랫폼 제휴를 먼저 받아야 해요.
  3. **절대 넣지 않을 것**: AI 가짜 후기 자동 게시, 경쟁사 서비스 복제(F)
- 개인정보는 **닉네임을 저장하지 않는 설계**로 위험을 크게 줄일 수 있어요.

## 확인하지 못한 것 (미확인)

- NAVER API HUB(새로 바뀐 네이버 검색 API 창구) 약관도 저장·AI 활용 제한이 같은지
- Meta 광고 라이브러리 API로 한국 일반 광고가 실제로 조회되는지(로그인과 인증이 필요해서 시험하지 못함)
- Meta 서비스 약관 본문(로그인하지 않으면 페이지가 안 열림)
- Google 광고 투명성 센터에 공식 API가 있는지
- 잡코리아-사람인 서울고법 사건번호
- 야놀자 민사 1심 이후 항소심 결과
- 개인정보위 안내서는 AI 학습용 기준이라서, 마케팅 봇에 그대로 적용되는지

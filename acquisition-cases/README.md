# 다른 서비스는 어떻게 사용자를 모았나 — 어디서 가장 많이 들어왔나

국내외 138개 서비스 사례 + 통계·벤치마크 153개 · 2026-11-24 조사 · 작성 전준연 · 목적: 쿠핀 PLUS(사장님)·ON(소비자) 신규 유입 방향 찾기

- **요약본(3쪽, 국내 기업 기준)**: `acquisition-summary.pdf` — 어떤 채널이 가장 많았나, 구분별 1위, 대표 수치, 쿠핀 적용. `python3 summary_kr.py`로 `summary-kr.html` 생성 후 같은 Chrome 명령으로 인쇄.
- **마케팅이란(2쪽)**: `marketing-basics.pdf` — 정의, 퍼널, 채널 종류, 대상별 차이, 지표, 정보통신망법 제50조. `python3 basics.py`로 `marketing-basics.html` 생성.
- **보는 법**: `index.html`을 브라우저로 열면 필터·검색이 됩니다. 인쇄본은 `acquisition-cases.pdf`.
- **데이터**: `cases.json`(합친 데이터), `data/*.json`(조사 묶음별 원자료), `data/insights.json`(종합 해석).
- **다시 만들기**: `python3 build.py` 후 PDF는 아래 명령.

```bash
python3 build.py && "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --no-pdf-header-footer \
  --print-to-pdf=acquisition-cases.pdf "file://$PWD/index.html"
```

## 한눈에 보기

- 채널별 유입 비중을 숫자로 공개한 곳은 적습니다. 138곳 중 주 채널을 수치로 뒷받침할 수 있는 곳은 46곳이고, 나머지는 대표 인터뷰·회사 설명 수준입니다(1장).
- 사장님 대상 서비스의 주 채널은 거의 셋 중 하나입니다: ① 직접 영업 ② 입소문·추천 ③ 대리점·파트너. 138곳의 주 채널 1~3위가 입소문·추천 23곳, 직접 영업 23곳, 대리점·파트너 18곳입니다. 광고가 주 채널인 곳은 소수입니다(2장).
- 사장님은 사람에게서 정보를 얻습니다. 국내 자영업자 정보 획득 경로는 주변 지인 44%, 인터넷 기사 30%, 세무사 17%(엠브레인 2021, 최신판 없음). 미국 로컬 사업자의 신규 고객 1위 채널도 입소문 35%(BrightLocal 2026). 정부 지원사업을 안 쓴 사장님의 76.2%는 '있는 줄 몰라서'였습니다(3장).
- 셀프 가입형에서 수치가 가장 분명한 것은 자발 가입·추천입니다. 캐시노트 초기 가입 절반이 입소문, Square 판매자 약 절반이 자발 가입, Toast 신규 약 3분의 2가 인바운드(그중 추천 20% 이상), Wix 유료 구독 59%가 오가닉·직접 유입.
- 매장에 드나드는 사람을 통한 유통이 물량을 만듭니다. 포스뱅크 내수 매출 94%가 대리점 경유, Clover 신규 매장 약 60%가 ISO·에이전트, Bill.com 고객 54%가 회계법인 경유, 토스플레이스는 VAN 대리점으로 3천 → 50만 매장(대신 2024년 순손실 536억 원).
- 양면 플랫폼은 한 동네·한 상권에서 공급을 먼저 채웠습니다. 배민 전단지 DB, 캐치테이블 하루 30~40곳 방문, 핫페퍼 '반경 2km·음식점만·하루 20곳', 당근 '대기 350명이면 동네 오픈'. 공급만 예산으로 모은 제로페이는 가맹점 63%가 실적 0이었습니다(이전 조사 research/marketing-cases-acquisition).
- 쿠핀에 가장 필요한 것은 우리 데이터입니다. 남의 비중은 참고일 뿐이라, PLUS 가입 UTM 기록(tn_company_attribution)과 가입 시 '어떻게 알게 되셨나요' 질문으로 직접 재야 합니다.
